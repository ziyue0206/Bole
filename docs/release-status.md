## 使用边界

当前资源方案面向 Linux x86_64、启用 AppArmor 的 Docker 主机。其他架构、rootless Docker、远程 daemon 或不提供相同内核能力的主机，需要另行适配。Codex 策略当前对应 0.169.0 的 x86_64 路径。

Isaac Sim 5.1 是此固定 RoboDojo 构建使用的版本。其[官方文档](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/installation/requirements.html)已标记为不再支持的旧版本；升级需要同时核对 RoboDojo、IsaacLab、cuRobo 和 Bole worker 的兼容性。

空缓存仍可能联网获取 Isaac 扩展和云端 USD 资产，尚无完整离线可运行承诺。上游 Dockerfile 的在线依赖也不构成逐字节可复现构建保证。

安全指标使用探索性阈值；非刚体、关节物体、脚本演员和传送带运动等仍影响覆盖或归因。指标不能作为机器人安全认证。

仓库不包含模型凭据、训练数据、权重、运行结果、学习镜像、Docker 镜像文件或大型资产。
